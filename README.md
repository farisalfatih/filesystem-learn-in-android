## About This Repository

This repository provides a structured approach to learning Linux filesystem commands. Each lesson includes:
- Clear explanations of commands
- Practical examples
- Hands-on exercises
- Best practices and tips

## Prerequisites

- Basic understanding of command-line interfaces
- Access to a Linux terminal or Linux emulator (WSL, macOS Terminal, or Android Termux)
- Basic text editor knowledge (nano, vim, or any editor of your choice)

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/farisalfatih/filesystem-learn-in-android.git
   cd filesystem-learn-in-android
   ```

2. Start with the lessons in order (see [Lessons Overview](#lessons-overview))

3. Practice the examples and complete the exercises

## Lessons Overview

### 1. Navigation Basics (`lessons/01-navigation/`)
Learn how to navigate the filesystem effectively:
- `pwd` - Print working directory
- `ls` - List directory contents
- `cd` - Change directory
- Understanding absolute vs relative paths

### 2. File Operations (`lessons/02-file-operations/`)
Master essential file manipulation commands:
- `touch` - Create files
- `cat` - View file contents
- `cp` - Copy files
- `mv` - Move/rename files
- `rm` - Remove files

### 3. Directory Operations (`lessons/03-directory-operations/`)
Learn to work with directories:
- `mkdir` - Create directories
- `rmdir` - Remove empty directories
- `rm -r` - Remove directories recursively
- Directory trees and structure

### 4. File Permissions (`lessons/04-permissions/`)
Understand Linux file permissions and ownership:
- `chmod` - Change file permissions
- `chown` - Change file ownership
- Understanding permission modes (rwx)
- Symbolic vs numeric notation

### 5. Searching and Finding (`lessons/05-searching/`)
Learn to locate files and content:
- `find` - Search for files and directories
- `locate` - Quick file location
- `grep` - Search within file contents
- `which` - Find command locations

### 6. File Content Operations (`lessons/06-content-operations/`)
Work with file contents efficiently:
- `head` - View file beginning
- `tail` - View file end
- `less` / `more` - Page through files
- `wc` - Word count and statistics

### 7. Practical Exercises (`exercises/`)
Apply what you've learned with real-world scenarios

## How to Use This Repository

1. **Sequential Learning**: Start with lesson 01 and progress through each lesson in order
2. **Hands-on Practice**: Type out each command yourself rather than copy-pasting
3. **Complete Exercises**: Each lesson includes exercises to reinforce learning
4. **Experiment**: Try variations of commands to deepen your understanding
5. **Create Your Own**: Practice by creating your own file structures and scripts
